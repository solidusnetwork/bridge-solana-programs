# Security policy

## Report a vulnerability privately

Use either channel:

- GitHub's private vulnerability reporting for this repository: open the **Security** tab and choose
  **Report a vulnerability**.
- Email **security@solidus.network**.

Please do not open a public issue or pull request for a vulnerability.

A useful report names the program and instruction, what you can cause with it, and a way to reproduce
it. A LiteSVM test is ideal. If it concerns a deployment, give the cluster and the program id.

## Scope

The programs and the gate library in this repository and their devnet deployments listed in the README.

## What happens next

The people who maintain the programs read the report and reply to you, in the advisory or by email,
whichever channel you used. Please give us time to fix an issue before you disclose it.
